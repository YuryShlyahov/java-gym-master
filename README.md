# Java Gym Master

Учебный проект на Java, посвящённый разработке приложения для управления фитнес-клубом.

## 📌 О проекте

**Java Gym Master** — проект, разработанный в рамках обучения Java в Яндекс Практикуме.

Цель проекта — закрепить знания Java, принципы объектно-ориентированного программирования и навыки разработки приложений с использованием автоматизированного тестирования.

Репозиторий содержит исходный код приложения и модульные тесты.

## 🛠 Используемые технологии

- **Java** — основной язык программирования
- **JUnit** — модульное тестирование
- **Git** — система контроля версий
- **GitHub Actions** — автоматизация процессов разработки и тестирования

## 🚀 Начало работы

### Требования

Для работы с проектом необходимы:

- JDK (Java Development Kit)
- IntelliJ IDEA или другая среда разработки Java
- Git

### Клонирование репозитория

```bash
git clone https://github.com/YuryShlyahov/java-gym-master.git
cd java-gym-master
```

### Запуск проекта

1. Откройте IntelliJ IDEA.
2. Выберите `File → Open`.
3. Укажите путь к клонированному репозиторию.
4. Настройте JDK в соответствии с требованиями проекта.
5. Найдите точку входа приложения в пакете `ru.yandex.practicum.gym`.
6. Запустите приложение.

## 🧪 Тестирование

В проекте предусмотрены модульные тесты, расположенные в директории:

```text
test/ru/yandex/practicum/gym/
```

Для запуска тестов:

1. Откройте проект в IntelliJ IDEA.
2. Перейдите в директорию `test`.
3. Выберите необходимый тестовый класс.
4. Запустите тесты с помощью IDE.

Тестирование позволяет проверить корректность реализации логики приложения и убедиться в работоспособности отдельных компонентов.
